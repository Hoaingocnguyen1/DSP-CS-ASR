# Knowledge Distillation: Whisper Teacher

This module handles the semi-supervised learning portion of the Code-Switching ASR thesis.
Since synthetic data is limited (~50 hours), we use a large foundation model (**Whisper Large-v3**) as a "Teacher" to generate pseudo-labels for unlabeled audio collected from Youtube/Podcasts.

These labels are formatted into SpeechBrain JSON manifests and merged with the structured synthetic dataset to train the "Student" (DSP W2V-BERT) system.

## Setup

You will need the `transformers` library, `torchaudio`, and optionally `insanely-fast-whisper` for massive speedups (not required by default script).

```bash
pip install transformers torch torchaudio
```

## Usage

Place all your collected, unlabeled, 16kHz `.wav` clips into a folder (e.g. `data/unlabeled_youtube`).

Then run the script:

```bash
python run_whisper_teacher.py \
    --audio_dir "data/unlabeled_youtube" \
    --output_json "outputs/pseudo_train.json" \
    --model "openai/whisper-large-v3" \
    --batch_size 8
```

## Output Format

The generated `pseudo_train.json` will match the format generated by `codeswitch-builder`, ensuring seamless integration into the SpeechBrain recipe.

```json
{
  "pseudo_00001": {
    "wav": "{data_root}/clip_01.wav",
    "length": 4.52,
    "words": "tôi cần một cái dashboard mới",
    "lid_tokens": "VI VI VI VI EN VI"
  }
}
```

## Integration with Student Model (SpeechBrain)

In your SpeechBrain `train.yaml`, simply add this file to your training dataset array or concatenate the JSON keys with your `train.json`.

*Note: The script cleans the `words` transcript recursively to remove punctuation and language tags, ensuring the Causal GRU Prompting module remains purely acoustic.*
